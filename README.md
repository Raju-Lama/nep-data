This repository contains unofficial OHLCV market data for the Nepal Stock Exchange (NEPSE).  
The data is scraped from publicly available sources and may not be 100% accurate or complete.  
It is provided **for educational and research purposes only**.  

NEPSE is the official source of stock market data.  
If you require verified and licensed data for production use, please consult NEPSE directly.
